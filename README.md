# Live Camera

Bun + TypeScript 单页摄像头播放器。默认只看 H.264 WebRTC 直播，不自动写入视频缓存。

## 启动

```bash
just live                         # 仅本机访问，每段最长 2 小时，H.265 录像
just live 10.10.10.3 8            # 指定局域网 / EasyTier IP，每段最长 8 小时
just live 10.10.10.3 2 h264       # 兼容性优先：录像改用 H.264
```

打开终端输出的播放器地址（默认 `http://127.0.0.1:8080/`）。远程观看时必须把本机可达 IP 作为第一个参数传入，例如通过 EasyTier 观看使用 `just live 10.10.10.3`。WebRTC 同时监听 UDP/TCP 8189，并只向浏览器发布该地址，防火墙需允许观看设备访问这两个端口。`just live` 会先停止旧会话。

直播连接遇到短暂网络波动时会先等待 WebRTC 自行恢复；持续断开或画面停止后，播放器会以最长 15 秒的退避间隔自动重连，也可点击「立即重连」。

## 网页操作

- 默认只显示直播；点击底部圆点开启录像，再次点击停止并保存。
- 录像开关是全局状态，多台设备共享。关闭网页不会停止录像，需要手动关闭开关。
- 点击圆点旁的录像列表图标，选择已完成的分段回放。尚未完成的当前段显示录制状态。
- 连续录制达到时长后，FFmpeg 在关键帧处自动分段，不重启编码器；已结束的段可以立即播放。
- 录像回放支持悬停时间预览、手机拖动浮层、精确时间选择、暂停和全屏。
- 录像进度条只对应当前文件，末端是录像结束；点击「直播」返回 WebRTC。
- 时间使用观看设备的本地时区，并显示 GMT 偏移。
- 录像列表可删除不需要的分段，删除不可撤销。录像进行期间不允许删除同次录像的分段。

## 存储与编码

文件保存在项目 `recordings/<会话 UUID>/`，每个文件对应一个分段：

```text
session.json       # 会话信息
segments.csv       # 已关闭分段的起止时间
00000.mp4
00001.mp4
```

默认 2 小时一段：以目标 1.5 Mbps 估算约 1.35 GB，2 Mbps 约 1.8 GB。
可配置 8 或 12 小时，但文件更大。分段时长不是磁盘总容量上限；不自动按 24 小时删除。
可用空间不足 1 GiB 时拒绝开启/自动停止录像，每 10 秒检查一次。其他进程同时写盘仍可能耗尽剩余空间。

- 直播：1080p / 20 fps，H.264 软件编码，最大 2 Mbps，兼顾低延迟和波动网络。
- 录像：只有开启时才从本机 RTSP 直播流转码，1080p / 20 fps，H.265 NVENC，目标 1.5 Mbps、峰值 2 Mbps。
- 录像需要再编码一次，画质存在一定损失；换来关闭录像时没有额外编码和写盘开销。
- H.265 录像需要观看设备支持 HEVC MP4；WebRTC 不需要 H.265。浏览器不兼容时可用 `h264` 录像选项（不改变已录文件）。
- 使用分片 MP4，提高意外中断后的可恢复性。正常停止会封尾；突发断电仍可能丢失末尾 GOP 或损坏文件。
- 重启默认关闭录像，已有录像重新加载。父服务退出时录像 worker 会结束 FFmpeg，避免无人知晓地继续写盘。

当前没有用户认证。**仅在可信局域网 / EasyTier 网络使用，不要直接暴露公网**；能访问页面的人可以开关录像、播放和删除文件。

## 开发与检查

```bash
bun install
bun run typecheck
bun run build
bun test
TEST_HEVC=1 bun test              # 另测本机 NVIDIA 硬件编码
```

服务端 `web/server.ts` 启动时自动用 Bun 构建 `web/app.ts`；浏览器只加载生成的 JS。
播放器需要 Bun；推流和录像需要 FFmpeg/FFprobe、MediaMTX，摄像头检查需要 v4l2-ctl。
浏览器测试有本机 Chrome/Chromium 时执行（也可设置 `CHROME_PATH`），用合成画面，不访问摄像头。

可只重启 Zellij 的 Player 面板更新页面，但会结束正在进行的录像。完整启动用 `just live`，停止用 `just stop`。

服务端环境变量：`PORT`（8080）、`RTC_PORT`（8889）、`RECORDINGS_DIR`、`RECORDING_SOURCE`（本机 RTSP `/cam`）、`RECORDING_CODEC`（h265）、`RECORDING_SEGMENT_SECONDS`（7200）。同一录像目录只运行一个服务实例。
